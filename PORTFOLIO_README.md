# Next-Level Astro Portfolio

🚀 **A stunning, recruiter-impressing portfolio built with cutting-edge technologies!**

This is a highly advanced, modern portfolio website featuring:
- **Astro 4** with islands architecture
- **Tailwind CSS** for beautiful styling
- **React, Vue, Svelte** components as islands
- **Advanced animations** with Framer Motion & GSAP
- **Interactive UI components** with Radix UI
- **Dark/Light theme** switching
- **Responsive design** for all devices
- **Smooth scrolling** navigation
- **Form validation** and interactivity
- **Performance optimized** for fast loading

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   Navigate to `http://localhost:4321/`

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```

## 📁 Project Structure

```
src/
├── components/           # All portfolio components
│   ├── Navigation.astro  # Header with theme toggle

│   ├── Experience.astro # Timeline with animations
```

## 🎨 Customization

### **Personal Information**
Update the following in the components:
- Name and title in `Hero.astro`
- About description in `About.astro`
- Skills and technologies in `Skills.astro`
- Work experience in `Experience.astro`
- Projects in `Projects.astro`
- Contact information in `Contact.astro`

### **Styling**
- Modify colors in `tailwind.config.js`
- Update fonts in `Layout.astro`
- Customize animations in component styles

### **Content**
- Replace placeholder images with your own
- Update social media links
- Modify contact information
- Add your actual projects and experience
